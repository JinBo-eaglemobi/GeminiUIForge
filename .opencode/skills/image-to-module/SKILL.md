# 设计参考图反向生成 UI 模块工程技能 (image-to-module)

本技能专门用于接收用户的界面参考图片输入，执行反向提取页面架构与图元工程任务。

---

## ⚖️ 规范隔离与执行准绳 (Specification Precedence & Isolation)

1. **遵循本技能规范**：执行本技能时，**忽略外部环境中其他不相干的通用或业务规范，完全按照本技能及其专用规范（[IMAGE_TO_MODULE_SPEC.md](IMAGE_TO_MODULE_SPEC.md)）来执行所有的业务动作**；
2. **遵守当前 Agent 规范**：当前承载调度的 **Agent 本身所设定的运行准则、安全门禁与工作流规范依然严格遵守**，确保执行过程既聚焦于专属业务标准，又受当前 Agent 的全局安全与流程机制保护。

---

## 🚨 技能激活前置硬性门禁：项目 MCP 连接探测

本技能能否成功激活并执行，**有且仅有一个绝对硬性前置条件**——**项目 MCP 服务必须已成功连接并就绪**。

### 门禁判定流程（触发后第一步）：
当本技能被调用时，AI **必须立即调用 `gemini-ui-forge_get_runtime_status` 探测项目 MCP 连接状态**：

1. **🔴 未连接 / 异常熔断（立即拒绝任务并停止）**：
   - 若调用返回未连接（如 `connected: false`）、报错、超时或 18330 端口不可达；
   - 🚨 **必须无条件立即拒绝本次任务，彻底停止后续一切操作，严禁继续读取规范或调用任何接口**；
   - **必须向用户明确说明情况**：
     > ❌ **[技能激活被拒绝] 项目 MCP 服务未连接**  
     > 本技能依赖运行态 Compose UI 树与 MCP 双向交互通信。当前检测到项目桌面端未启动或 MCP 服务离线（18330 端口未连通），无法进行图元逆向建模与校准。  
     > 💡 **请先启动桌面端应用程序**（执行 `./gradlew :desktopApp:run` 或通过 IDEA 运行配置拉起），待 MCP 成功连通后再发送生成指令。

2. **🟢 已连接（放行准入）**：
   - 仅当探测到 MCP 状态正常在线、应用处于连通状态时，方可正式激活本技能并进入下方执行准绳。

---

## 📖 业务执行准绳：二元架构与专用规范

准入通过后，AI **必须首先使用 `read` 工具读取同目录下的 [IMAGE_TO_MODULE_SPEC.md](IMAGE_TO_MODULE_SPEC.md)**，并根据系统配置 `isUiFollowEnabled` 自适应执行以下双分支流程之一：

👉 **专用执行规范文档**：[IMAGE_TO_MODULE_SPEC.md](IMAGE_TO_MODULE_SPEC.md)

### 模式自动分流体系：
1. **分支 A：跟随模式 (`isUiFollowEnabled == true`)**：
   - **拟人全流程前台交互**：严禁直接越级调用无头接口；
   - **前台手势锁定**：主界面内容区手势自动锁定（防止用户乱点破坏时序，放行最底部 30dp 状态栏）；
   - **大厅生成中标记**：卡片展示“AI 逆向生成中...”动效并拦截点击进入；
   - **拟人链路**：大厅归位 $\rightarrow$ 点击“生成模板”按钮 $\rightarrow$ 输入参考图信息与工程名并点击生成 $\rightarrow$ 等待完成自动跳转工作区 $\rightarrow$ 首态自愈 $\rightarrow$ 逐图元独立隔离与 1:1 局部高清特写核验 $\rightarrow$ UI 点击保存 $\rightarrow$ 解除锁定并交付。
2. **分支 B：快捷无感模式 (`isUiFollowEnabled == false`)**：
   - **全程后台静默执行**：程序在哪个界面就保持在哪个界面，零界面跳转，绝不干扰用户前台操作；
   - **大厅生成中标记**：卡片展示“AI 逆向生成中...”动效并拦截点击进入，保护数据完整性；
   - **离线无头链路**：MCP 快捷生成 $\rightarrow$ 后台离线首态自愈 $\rightarrow$ 逐图元离线 Skia 渲染 1:1 局部特写并物理落盘本地 $\rightarrow$ AI 离线多模态审校与纯数据纠偏 $\rightarrow$ 离线持久化 $\rightarrow$ 解除生成中标记并交付。

### 强制红线警示：
- ❌ **严禁编写外部脚本绕过 MCP 原生工具链（Native MCP Only）**：
  任何 AI 在执行本技能时，**绝对禁止自行编写临时 Python/Node.js/PowerShell 脚本直接读写、篡改本地 `template.json` 或切片文件**！图元的增删改移必须且只能调用 MCP 原生工具：
  - 新增图元：调用 `add_block`（支持指定父容器、相对坐标与绝对选区）；
  - 修改图元：调用 `update_block`（支持修改局部坐标、绝对选区、提示词与类型）；
  - 调整层级/顺序：调用 `move_block`；
  - 删除图元：调用 `delete_block`。
  严禁任何脱离 MCP 闭环的野蛮外挂脚本行为，确保任何全新 AI 环境均能 100% 原生复现与执行！
- ❌ **严禁污染模板资产与工程目录（Zero Asset Pollution）**：
  严禁在工程模板根目录、`assets/` 目录或项目代码区生成任何临时的排查图片、调试脚本或垃圾文件（如 `crop_*.png`, `ref_*.png`, `test_*.py` 等）。所有核验与审查必须通过内存/MCP 工具管道流转（如 `render_template_overlay` 或 `inspect_block_with_reference` 统一落盘于系统临时目录）。
- ❌ **转轴网格图元全量补齐铁律（Complete Reel Grid Matrix）**：
  游戏老虎机/转轴区域（`UIBlockType.REEL` 或网格容器）下的符号图元，**必须 100% 完整覆盖整个可见网格的全部格子（例如 5 列 × 3 行必须完整声明全部 15 个格子图元）**，绝对严禁以“符号种类去重”为由遗漏重复符号的网格位置！每个格子图元必须具备规整的行列网格相对坐标 `bounds` 与全局选区 `cropRect`。
- ❌ **像素级紧致包裹与绝对零重影铁律（Zero Offset & Zero Ghosting）**：
  每个图元的 `bounds`（相对直接父级）与 `cropRect`（全局绝对坐标）必须像素级严丝合缝紧致包裹设计图中的视觉元素本体（如返回按钮发光圆环、菜单按钮齿轮、胶囊外框）。严禁尺寸偏大、偏小或偏心，彻底根绝因切片采样与背景图错开而产生的“重影双按钮”视觉缺陷！
- ❌ **严禁全屏截图交差**：不论哪种模式，必须且仅能截取目标图元周围局部外扩 32px 的 1:1 高清特写；
- ❌ **未生图阶段边框包裹吻合度为唯一准绳**：在初次逆向生成模板未生图贴图阶段，绝对禁止用纹理比对算法误判，唯一依据是“青色外边框对参考图中按钮/文字/图标等预定内容的物理包裹紧凑度（零切边、零过度留白、严密居中）”，发现偏差必须调用 `update_block` 或 `add_block` 纠偏；
- ❌ **严禁跳过微观审校与抽检走过场**：首态算法自愈只是机器初筛，必须 100% 遍历全量非纯容器业务图元，逐个查看特写并生成全量核验报告表格；
- ❌ **严禁与生图混淆**：严禁调用 `generate_block_asset` 或 `generate_all_assets`。
