## 一、 模块核心定位

UI Studio 独立工作台是 Gemini UI Forge 针对现代游戏 UI 切片资产拼合与界面排版设立的专属工程环境。与传统 Slots 模板依赖整景设计图不同，UI Studio 采取**纯切片素材驱动架构**：支持多视图界面管理、树形素材库拖拽组装、容器专属独立视口多 Tab 编辑、自由拖拽分割线与毫秒级属性检查。

## 二、 核心功能清单

### 1. 三栏响应式架构与手势调宽系统 (Splitter System)
- **左右中三栏解耦与自由调整**：
  - 左侧复合面板、中间交互画布与右侧属性检查器通过 `VerticalSplitter` 相互解耦；
  - 基于 Compose 官方生产级 `Modifier.draggable` 一维手势封装，设置 `startDragImmediately = true` 确保指针即触即动、零启动死区；
  - 左右面板宽度支持双向自由拉伸，并具有合理的物理最小与最大边界夹具（如 240dp ~ 480dp），手势协程长效保活，彻底杜绝高亮锁死与手势中断。
- **左侧上下子面板与水平手柄 (HorizontalSplitter)**：
  - 左侧上栏为页面视图列表（ViewsPanel），下栏为树形素材库（AssetPanel）；
  - 中间镶嵌 `HorizontalSplitter` 水平分割手柄，支持上下自由调整列表与素材库的显示高度配比。

### 2. 页面视图管理系统 (ViewsPanel)
- **多页面/多场景统一管理**：
  - 支持在一个工程中创建并管理多个独立的游戏视图（如 Main 主界面、Lobby 大厅、Settings 设置弹窗、Backpack 背包等）；
  - 支持视图新建、重命名、复制副本与物理删除（含二次确认保护）；
  - 单击视图项快速在中间画布加载其图元树，双击可在顶部标签栏开启独立视口。
- **新建视图自定义尺寸与快捷预设配置 (NewViewDialog)**：
  - **主选项：自定义宽高纯整数输入框**：弹窗顶部核心区域提供「画布尺寸 (自定义输入)」的宽度 (W) 与高度 (H) 并列输入框，统一接入 `NumberOutlinedTextField`（整数模式），严密过滤小数点与浮点片段，仅允许纯整数输入；默认自动带入当前工程的全局基准分辨率，支持滚轮/拖拽平滑调值及 100~10000 范围限制校验；
  - **次级选项：快捷预设配置列表**：提供「横屏大屏 (1920×1080)」、「横屏标清 (1280×720)」、「竖屏高清 (1080×1920)」与「移动端小屏 (720×1280)」四组行业常用标准分辨率快捷配置（彻底移除同值冗余的「继承工程」选项）。点击任意预设卡片即可秒级填充至上方宽高输入框；当自定义数值与某预设精确匹配时（首项匹配原则），该预设卡片自动高亮选中并呈现紫色背景与勾选标记；一旦用户手动改写数值脱离预设，预设项自动脱钩取消高亮；
  - **人机工程学与规范化保障**：严格遵循 8pt 设计系统与 `dialogAlertWidth` 紧凑尺寸，内置完备的 I18n 国际化双语支持与 `AppIconButton` 悬浮提示。

### 3. 多标签独立视口与组件-页面一体化系统 (Viewport Tabs & Component-Page Unification)
- **复合组件与视图页面 (UIStudioPage) 1:1 单实例强绑定**：
  - UI Studio 彻底废除传统易割裂的独立 `CONTAINER` 类型概念，实行“组件即页面”的一体化架构；
  - 凡是由多切片组合而成、或包含内部子图元的复合组件（例如老虎机滚轴 `slots_window`、控制底栏 `bottom_control_hud`），系统均自动在工程中为其生成并绑定对应的独立子页面（`UIStudioPage`），具有独立的视口分辨率、背景色与子图元列表；
  - 左侧「视图界面」面板采用层次化树状渲染，根页面下方紧随并缩进展示其所绑定的子页面（带有 `↳` 箭头与专属「组件」徽章）；
- **组件页面视口新开与聚焦（仅限独立页面 VIEW 打开 Tab 铁律）**：
  - **能用顶部 Tab 打开的只能是单独页面的 `VIEW`**：仅当组件为绑定了独立页面（`targetPageId != null` 且在 `studioPages` 中真实存在）的 `VIEW` 组件时，双击画布或图层树中的该组件（或在左侧「视图界面」单击该页面条目），系统才会在顶部标签栏新开或激活对应的独立页面标签页（`openViewTab`）；
  - **严禁非独立页面容器打开临时 Tab**：普通的非独立页面内联容器（`targetPageId == null`）双击或右键不再打开临时容器 Tab，顶部标签栏（`UIStudioPageTabBar`）100% 纯粹承载真实存在的独立页面（`UIStudioPage`）；
- **父子页面双向联动与独立性守恒**：
  - **主界面调整不影响子组件**：在主页面（如 MainPage）调整该复合组件整体的 X/Y 或宽高时，仅改变其在主页面的承载形态，子组件内部的相对坐标与排版保持独立守恒；
  - **子界面修改实时镜像回显**：在组件子页面内部选中子图元修改 X、Y、宽 W、高 H 时，不仅当前子页面画布与微缩预览图即时变化，主页面中的对应复合组件也会实时镜像更新；
  - **图片渲染绝对贴合边界**：画布组件与微缩预览均采用 `ContentScale.FillBounds` 渲染，使图片严格按照用户设定的 `宽 W × 高 H` 矩形外框等比或拉伸贴合，杜绝单边修改宽高图片不变化的现象；
- **标签页状态管理与职能单一化**：
  - 顶部标签栏统一管理所有根页面与组件子页面 Tab，支持多标签平滑切换、关闭全部标签页（`AppIconButton` COMPACT 阶）；新建视图入口统一且唯一收拢于左侧「视图界面」面板 Header，确保顶栏功能纯粹。

### 4. 素材库 PC 端多选交互与批量管理 (AssetPanel)
- **标准修饰键多选**：支持常规单击（单选）、`Ctrl/Cmd + 单击`（追加/反选）与 `Shift + 单击`（区间范围连续多选）；
- **动态微型批量操作栏 (UIStudioAssetBatchBar)**：多选（>1）时自动呈现已选 N 项徽章、全选、取消多选与批量删除垃圾桶胶囊；
- **Windows 物理键盘 Delete 极速删除**：焦点位于素材面板时，按下物理 `Key.Delete` 键一键唤起批量删除二次确认弹窗；
- **专属右键多选上下文菜单**：在已多选素材上右键弹出批量操作菜单，支持批量彻底删除、批量跨文件夹移动（`moveAssetsToFolder`）、全选与取消选择；
- **二次确认防误触**：批量删除强制弹出 `AppConfirmDialog`，经用户授权后物理抹除磁盘文件并即时原子刷盘。

### 5. 素材切片拖拽排版与画布交互
- **切片拖拽即生成图元**：
  - 支持从左侧素材库中选中任意切片，直接拖拽至中间画布释放；
  - 系统自动根据切片真实物理分辨率初始化图元尺寸，并自动挂载对应切片资产 Hash；
- **微观对齐与智能吸附**：
  - 画布内置边缘几何对齐辅助线，图元在移动或拉伸时，靠近相邻图元或容器边缘（$\le 5\text{px}$）自动触发磁力吸附；
  - 8 方向拉伸控制锚点 100% 统一复用 `RectTransformHelper`，光标物理绝对定位。

- **画布点击选中与锁定图元穿透规则**：
  - 仅对未锁定图元（`!block.isLocked`）挂载画布点击、双击与拖拽手势；被锁定的遮罩或辅助图层（如覆盖在顶层的辅助面板）直接放行指针事件穿透到底层可交互图元，杜绝锁定图层吞噬下层组件点击；
  - 画布外层点击命中检测统一结合 `scale` 与 `density` 逆映射至 `.dp` 逻辑坐标系，确保在不同 DPI 与布局模式下均能精准命中图元；主视图模式下拖拽嵌套子图元统一路由至顶层根父组件。

### 6. 右侧动态属性检查器 (PropertyPanel) 与工业流线排版体系
- **100% 纵向全高舒展视口与单一工业流线风 (STUDIO_COMPACT)**：
  - 彻底废除旧版高占位经典卡片风（`UIStyleMode.MATERIAL_CARD`），将工业流线风确立为全系统唯一排版标准（无冗余外层卡片套娃、折叠分组标题 `InspectorSectionHeader` 极简分隔、双列对称垂直共线）；
  - 数值调节与表单组件 100% 统一收拢至极简封装组件体系：**唯一通用行容器 `InspectorPropRow`**（左列固定 `inspectorLabelWidth`、右列统一 `weight(1f)` 锁死全行左起基准线与 50%/50% 双列栅格）、`InspectorSectionHeader`、`InspectorCheckboxRow`、`InspectorSegmentedIconGroup`，以及升级后的统一组件 `DropdownInputField`（底层接入 `AppMenu` + `AppMenuItemRow` + `Modifier.matchParentSize()` 向下 4dp 精准展开防遮挡）、`NumberOutlinedTextField`（支持内嵌前缀标签 `prefixTag` 实现与文本/下拉控件 0 误差左对齐）、`SelectAllOutlinedTextField`（失焦/回车自动提交 + 高对比主色光标）与 `ColorPickerField`（`showFloatingLabel = false` 流线配色行）；
  - 全部尺寸（高度、标签宽度、输入框宽度、间距、图标尺寸）与字号 100% 动态取自 `LocalAppSpacing.current` 与 `MaterialTheme.typography.*`，严禁写死 `.sp` 与静态布局标志；切换 **桌面高密度 (`COMPACT`)** 与 **移动端触控 (`TOUCH`)** 布局模式时，字号、控件热区高度与间距全自动同步缩放；
  - 指针悬停数值输入框即可滚轮/水平拖拽平滑微调。
- **全组件专属属性配置面板 (UIStudioSpecificProperties)**：
  - 根据选中的图元类型，自动分发呈现对应的无框流线专属配置面板：
    1. **`LIST` (动态列表与网格)**：配置 `listLayout`（SingleColumn/SingleRow/FlowHorizontal/FlowVertical/Pagination）、`lineCount`/`columnCount`（行数/列数）、`lineGap`/`columnGap`（行距/列距）、`itemWidth`/`itemHeight`（项宽/项高）、`align`/`verticalAlign`（业内通用水平/垂直双组三段式图标切换器 `InspectorSegmentedIconGroup`）、`overflow`/`scrollType`、`selectionMode`、`defaultItem`（**子项单页**：禁止手动输入，支持只读下拉列表选取或直接从左侧「视图界面」拖拽页面释放赋值；在画布或图层树**双击 `LIST` 组件**或通过右键菜单可直接打开该子项单页视图），以及默认启用的 `autoResizeItem`（默认 `true`）、`foldHiddenItems`、`scrollItemToViewFully` 复选开关；
    2. **`BUTTON` (交互按钮)**：配置文案 `text`、`downEffect`（按压变暗/中心向心缩放）、`downEffectValue`、`mode`（Common/Check/Radio）、单选关联控制器与页面 ID；
    3. **`TEXT` (文本与数值)**：配置内容 `text`、字号 `fontSize`、颜色 Hex、排版对齐、富文本 `isUbb` 开关、加粗、倾斜、下划线、单行限制、描边与行间距；
    4. **`INPUT` (文本输入框)**：配置占位提示 `promptText`、字号、颜色、最大输入长度限制与密码模式；
    5. **`PROGRESS_BAR` (进度条)**：配置当前数值 `value`、最大数值 `max` 与标题格式（百分比/数值/无文本）；
    6. **`SLIDER` (滑动条)**：配置最小值 `min`、最大值 `max`、当前值 `value`、步长 `step` 与整型限制；
    7. **`COMBO_BOX` (下拉框)**：配置选项列表（逗号分隔）、默认选中项索引与展开可见项数；
    8. **`LOADER` (动态装载器)**：配置默认地址 `url`、填充拉伸模式 `fill` 与视口强裁剪 `clip`；
    9. **`SPINE` (骨骼动画)**：配置动作名 `animationName`、皮肤名 `skinName`、循环播放与速度；
    10. **`SCROLL_BAR` (滚动条)**：配置固定滑块尺寸与微调箭头；
    11. **`COMPONENT` (容器组件)**：配置一维流式排版模型（vertical/horizontal/none）、流间距 `gap`、折行 `flexWrap`、交叉轴/主轴对齐约束、滚动与背景色；
    12. **`IMAGE` (图片图元)**：配置缩放拉伸模式与九宫格切边拉伸数据（sizeGrid 四周固定边距）。
- **即时持久化与撤销快照**：
  - 修改面板中任何配置参数，通过 `updateBlockProperties` 即时更新图元树并标脏，且完整纳入撤销重做（Undo/Redo）快照栈。

### 7. 左侧边栏高保真实时预览面板 (UIStudioPreviewPanel)
- **左侧边栏三层就近联动布局**：
  - 迁移至左侧边栏最底部（位于素材库与图层树下方，中间以 `HorizontalSplitter` 水平分割并支持自由拖拽高度）；
  - **就近直观联动**：在左侧素材库点选切片或在图层树点选图元时，左侧底部就近实时呈现高清切片原画与微缩预览，视线零跨度；
- **双模态智能预览感知**：
  - **素材模式 (AssetPreviewView)**：当左侧素材库选中特定切片资产时，自适应呈现切片原画与素材规格详情（名称、物理尺寸、文件哈希）；
  - **图元模式 (BlockPreviewView)**：当画布选中切片图元时，动态加载所绑定切片原画并展示图元尺寸与坐标；
  - **容器与引用页面穿透模式 (ContainerPreviewView)**：
    - **自动穿透平级引用页面 (`targetPageId`)**：当选中的复合容器或子组件引用了独立平级页面时，自动穿透展开其内部所有子图元；
    - **多层嵌套相对坐标累加与透明度继承**：逐层累加局部相对偏移量 `(relX, relY)` 与级联透明度 `effectiveOpacity`，将深层嵌套的叶子切片图元按精确网格相对坐标微缩排布；
    - **1:1 真实画面最终渲染**：直接异步加载内部所有切片的本地物理图片，在左下角微缩视口中 100% 完整呈现最终视觉切片全貌；
    - **信息卡片智能感知**：清晰呈现当前组件 ID、关联的引用页面 ID、微缩容器实际几何尺寸及所包含渲染图元的总数量。
- **沉浸式原寸灯箱大图查看 (CommonImageLightbox)**：
  - 预览视口右上角挂载半透明毛玻璃放大镜快捷按键（`Icons.Default.ZoomIn`），画面主体支持点击直接唤起灯箱；
  - 基于真实磁盘绝对物理路径无损加载，支持鼠标滚轮以光标为中心 0.1x~8.0x 平滑缩放、1:1 原寸还原、拖拽平移与 ESC 一键关闭；
- **素材库相对路径展示与一键复制**：
  - 信息卡片底部新增结构化相对路径行（展示 `📁 templates/{projectName}/assets/...`），内置 `Modifier.copyOnClick`，单击整行一键复制相对路径至系统剪贴板。

### 8. 悬浮式 AI 架构师协同入口

## 四、 行业业务规则与安全红线

1. **【素材唯一主键 Hash 守恒】**：素材切片在整个工作台内以内容 SHA-256 Hash 为唯一不可变标识，杜绝同名重命名引发的资产错乱；
2. **【分割线手势保活铁律】**：严禁在业务界面裸调手势，必须统一复用[08 全局设计系统与通用基础组件规范](08_全局设计系统与通用基础组件规范.md)中的标准 Splitter 组件，确保拖拽停止时 100% 释放拖拽状态；
3. **【视口状态无损切换】**：多标签页切换或退出进入容器视口时，原视口的缩放比例与平移偏移行程必须无损保留；
4. **【排版应用显式授权触发红线】**：AI 生成的排版方案严禁在对话流式结束或生图工具收口时自动向画布中央强推全屏模态弹窗，必须严格遵循“气泡常驻操作胶囊 + 用户主动点击按需唤起确认”的无感原则，保障用户视觉审阅与排版探索的绝对掌控权；
5. **【全平级页面与多重引用实例架构红线】**：UI Studio 内部所有页面（`UIStudioPage`）地位完全平级，无任何硬编码的“谁是谁的子页面”层级从属。页面间通过组件实例的 `targetPageId` 进行单向或多重随意引用；源页面修改时自动跨页面将内部元素镜像同步到所有引用实例中，而在宿主页面调整实例坐标与宽高仅影响其实例外观，确保任意组件可在全项目多页面中自由复用；
6. **【页面引用零篡改存储与纯动态按引用渲染架构红线 (Zero-Interference Persistence & Dynamic Reference Rendering)】**：
   - **保存零篡改与原样保留 (Zero-Interference Persistence)**：彻底废除历史遗留的保存自动脱敏（`stripPageReferences`）逻辑。在将平级独立页面物理落盘至 `pages/{pageId}.json` 时，系统执行 1:1 原样序列化。若历史或脏数据中存在 `children`，程序绝对不理会、不干预、不破坏，原封不动持久化保留，确保用户正在修改或暂存的数据永不被误删；
   - **加载零注水 (Zero-Hydrate Loading)**：彻底废除历史遗留的加载注水（`hydratePageReferences`）逻辑。系统加载反序列化各个平级页面时，原样读取各自独立 JSON 并仅重建自身父子指针（`.bindParents()`），绝对严禁跨页面深拷贝图元树并强行塞入宿主容器的 `children` 中；
   - **绝对禁止后台自动切割与隐式建页 (Ban Auto-Split)**：彻底废除 `ensurePageForBlock` 与后台自动拆分逻辑，坚决杜绝程序在加载或渲染时背着用户私自将带子图元的容器自动切割为独立子页面；
   - **渲染层纯动态递归解析 (Pure Dynamic Reference Rendering)**：画布在收集渲染图元时，一旦图元持有 `targetPageId`（组件实例），无论其自身在持久化层是否存留历史 `children`，渲染引擎一律**直接忽略自身 children**，纯动态递归按引用实时解析并投影目标平级页面的最新图元树，实现数据零拷贝与界面 100% 动态实时联动；
   - **常驻数据完整性诊断与定位 (Studio Data Diagnostics & Banner)**：在画布视口顶部居中挂载常驻数据完整性诊断横幅（`UIStudioDataIntegrityBanner`），长期、直观地提示哪个视图页面的哪个组件存在“既引用了页面又包含冗余 children”或“引用目标页面不存在”的异常，并提供一键直达与展开定位；
   - **AI 工具契约硬拦截 (AI Tool Reference Invariant & Hard Rejection)**：万能排版工具 `edit_view_layout` 的 Schema 明确声明“设置 targetPageId 时绝对严禁传入 children”。在 `REPLACE_PAGE`、`REPLACE_CONTAINER` 与 `PATCH` 数据审核层执行 100% 刚性硬拦截：凡发现试图向引用组件注入 `children`、或在图元中同时传入 `targetPageId` 与 `children` 的操作，系统一律立即打回拒绝并明确指出具体违规组件与修复指引，从源头彻底杜绝新脏数据产生；
   - **双通道异常诊断工具 (diagnose_view_data)**：封装独立的视图数据完整性诊断工具，100% 复用 `StudioDataDiagnostics` 逻辑，支持按 `viewName` / `viewId` 定向过滤或扫描全工程，向外部 MCP 客户端与内部 AI 架构师输出结构化 JSON 报告，详细列明问题分类（`REFERENCE_WITH_CHILDREN` / `TARGET_PAGE_NOT_FOUND`）与具体排版修复指引；
   - **纯粹基础组件体系与废除冗余字段**：全系统 `UIBlockType` 收敛为 13 个纯粹基础 UI 组件枚举（`BUTTON, VIEW, TEXT, IMAGE, LIST, SPINE, COMBO_BOX, PROGRESS_BAR, POPUP_MENU, LOADER, SCROLL_BAR, SLIDER, INPUT`），彻底删除 `REEL, SPIN_BUTTON, WIN_DISPLAY, BACKGROUND, SYMBOL, HEADER, FOOTER, CONTAINER` 等业务耦合枚举，并彻底移除 `BaseBlock` / `UIStudioBlock` / `UIBlock` 中冗余的 `isPureContainer` 字段（复合容器或页面实例统一使用 `UIBlockType.VIEW` / `UIBlockType.LIST`）；
   - **全量基础组件专属 Properties 高级配置与画板实时渲染红线**：全量 13 个基础组件均全面支持挂载专属高级配置 `properties: BlockProperties`；属性检查器中对多行文本等大文本组件提供上下舒展布局与充裕高度，支持直观换行与段落审阅；画板渲染层（`UIStudioBlockItem`）全面接入真实文本与样式渲染（`RenderStyledText`），当图元为 `TEXT` 时直接按照配置的 `textColor`、`textSize`、`isBold`、`horizontalAlign`、`verticalAlign` 以及 `letterSpacing`（字符间距实时生效）等参数实时在画布上绘制带样式的排版文字；
   - **文本组件自动大小 (autoSize) 与双向自适应联动红线**：文本组件属性对齐 FGUI 标准 5 项 `autoSize` 枚举（`(无)` none、`宽度和高度` both、`高度` height、`自动收缩` shrink、`显示省略号` ellipsis），默认值为 `both`；字号与字距严格限制为纯整数（`Int`，禁止小数）；当文本组件处于 `both` 状态时，文本内容变动将即时动态测算最新外包尺寸并更新 bounds，使属性栏 W/H 实时刷新；而一旦用户手动输入修改宽 W 或高 H，系统自动将 `autoSize` 从 `both` 联动切换为 `none`（无），防止自适应与定宽定高冲突；
7. **【原图尺寸物理守恒与一键复位红线】**：属性面板必须提供「原图尺寸」一键复位能力，自动依据图元绑定的素材物理 Hash（或引用页面的源尺寸）秒级复位当前组件的宽 W 与高 H（保持左上角定位恒定），杜绝拉伸失真后无法还原初始比例的体验缺陷；
8. **【项目公用配置文件、单一页面 ID 契约与复合页面分包存储红线】**：UI Studio 项目工程存储严格遵循项目公用配置与复合页面分包架构（对齐 Figma / VSCode 工业级工程标准）。主配置文件 `template.json` 彻底纯净化为项目级公用配置文件（`UIStudioProjectConfig`，`formatVersion: "2.0"`），专职记录工程元信息（`projectId`、`projectName`、`createdAt`、`updatedAt`、`gameProjectPath`）以及仅含唯一标识 `id` 的 `pageIndex` 页面索引清单，绝对禁止包含任何界面专属私有信息；`UIStudioPage` 彻底废除 `nameStr` 字段，**全系统仅保留唯一的 `id` 属性，且物理文件名 `templates/{projectName}/pages/{id}.json` 与 `page.id` 100% 强绑定**（重命名视图即同步更新 `page.id`、关联图元的 `targetPageId` 并自动删除旧文件名）；所有 JSON 文件的物理落盘必须通过 `saveToFileAtomic` 执行原子交换协议（Temporary Swap + 底层 `fsync` 硬件刷盘 + `ATOMIC_MOVE` 原子替换），彻底杜绝系统崩溃或断电导致配置坏损。

9. **【AI 页面命名纯英文标识符红线】**：AI 架构师助手在通过工具（`apply_view_layout`）自动创建或重构视图界面时，其视图名称（`viewName`）必须且仅能使用合法的英文、数字与下划线标识符（如 `Game_HUD`, `Settings_Dialog`, `Reel_Column`），绝对严禁使用任何中文字符；后端装配层（`UiStudioLayoutService.assembleViewPage`）内置 ASCII 正则自愈清洗与英文时间戳兜底断言，彻底杜绝中文页面标识在多平台转译、文件导出与引用索引中的潜在隐患；同时，用户在客户端手动通过新建弹窗创建或重命名视图界面时完全不受此限制，继续享有完备的中英文多语言命名自由。

10. **【AI 排版数据格式刚性审核准入与引用智能路由红线 (AI Layout Rigorous Validation & Reference Auto-Routing)】**：
    - **数据格式刚性准入审核**：系统在接收到 AI 返回的视图排版数据（`apply_view_layout`）或图元增量补丁（`patch_view_elements`）时，必须执行前置的数据完整性与合法性刚性审核。凡出现：图元缺失必填 `id`、同一视图内 `id` 冲突、图元宽或高 $\le 0$、引用了已废弃的 `CONTAINER` 类型、图元声明的 `targetPageId` 在工程中不存在、或在页面引用实例节点（`targetPageId != null`）的 `children` 中内联塞入子图元等违规情况，系统一律立即拒绝执行并阻断，直接反馈执行失败，并通过 Toast 气泡与执行结果明确告知具体的违规字段与错误原因；
    - **页面引用实例智能自动路由与零反向污染**：在执行 `ADD` 增量补丁时，若目标父节点（`parentBlockId`）为页面引用组件（`targetPageId != null`），系统严禁将其直接追加到当前宿主页面的 children 中，而是智能拦截并自动路由重定向追加至对应的目标独立子页面（`targetSubPage`）顶层；同时在任何子页面更新或保存时，**绝对禁止调用 `syncReferencedPageRecursively` 将子页面的图元反向复制塞回宿主引用节点的 `children` 中**；当外部通过 `REPLACE_PAGE` 重建页面、或通过 `PATCH` (`op = "UPDATE"`) 显式传入 `children: []` / 绑定 `targetPageId` 清理了该节点的 `children` 时，其 `children` 彻底清空为 `emptyList()` 并落盘，不再保存任何历史 `children`（而对于未经外部触碰处理的历史本地文件节点，仍原样保留磁盘原有的 `children` 供后续新建页面提取）；
    - **纯容器/引用节点免误绑与切片槽位内切等比适配 (Contain Fit)**：`autoFitAssetsToSlots` 严格跳过 `isPureContainer == true` 与 `targetPageId != null` 的节点，杜绝容器被自动绑上贴图或篡改尺寸；当绑定切片的图元顯式指定了槽位框 `[x, y, w, h]` 且与切片原生宽高比存在偏差（$> 5\%$）时，采用框内等比内切居中（`scale = minOf(w / assetW, h / assetH)`），确保切片既保持原生纵横比不变形，又绝不超出或撑破父容器底边。

11. **【游戏项目独立保存目录与防缓存污染红线】**：游戏项目的源码、依赖库与运行编译产物必须保存在用户显式指定的外部独立物理目录中，**绝对严禁**存放在程序自身私有缓存目录（如 `~/.geminiuiforge/templates/...`）下，从底层杜绝因程序缓存清理导致用户代码被误删的严重隐患；
12. **【专属配置文件单一事实源红线 (forge-game.json)】**：未包含有效专属识别配置文件 `forge-game.json` 的目录，系统坚决不认定为有效游戏工程；运行预览时若项目已激活则直接浏览器极速拉起，未激活则强制弹出向导弹窗完成环境就绪、脚手架写入与完整构建流水线校验；
13. **【纯代码 UIFactory 界面导出与切片物理同步红线】**：
    - **规范化纯代码构建**：游戏端 UI 一律严格遵循《纯代码创建UI规则 (UIFactory)》标准规范，通过 `tsCore.UIFactory` 配置化工厂驱动纯代码 FGUI 界面（严禁使用 Laya 原生对象）。UI Studio 当前视图自动转换为 `game/src/ui/layoutConfig.ts`（包含 icon、panel、尺寸、坐标、不透明度与层级树），并在主类 `game/src/Main.ts` 中通过 `UIFactory.createPanel(layoutConfig, width, height)` 纯代码构建并挂载至 `fgui.GRoot.inst`；
    - **切片素材原子物理同步**：每次导出时，系统自动扫描当前视图引用的全部素材切片，并将其从程序数据目录（`~/.geminiuiforge/templates/{projectName}/assets/...`）物理同步拷贝至游戏工程的静态资源目录（`build/res/gameui/<fileName>`）；全局统一配置 `tsCore.UIFactory.resBasePath = "res/gameui/"`，实现切片相对路径的无缝静态寻址与加载；
    - **GM 动态脚本批加载流水线与 Google Analytics 脱敏**：静态脚手架（`build/index.html` 与 `build/index.js`）完全对齐 GM 商业工程的动态分批脚本加载流水线，统一引入 `common.min.js` 及其类型定义 `common.d.ts`，彻底剥离第三方谷歌统计（Google Analytics）逻辑，确保单机纯净、秒级启动并在本地 `http://localhost:1234/` 端口实现 100% 视觉无损预览。
14. **【纯代码组件按 Type 严格分发与按钮点击变暗特效红线】**：
    - **严格 Type 单一事实源分发**：系统将 UI Studio 图元树转换为 `layoutConfig.ts` 时，**必须 100% 严格依据图元自身的强类型字段 `block.type`（`UIBlockType`）决定导出组件类型，绝对禁止依据图元名称（如包含 btn/button）进行任何模糊猜测**；
    - **按钮默认点击变暗特效**：凡 `block.type == UIBlockType.BUTTON` 的组件，导出为 UIFactory 的 `type: "button"`（对应 `fgui.GButton`），并**默认且强制注入点击变暗特效**（`downEffect: 1, downEffectValue: 0.8`）；若按钮自身绑定切片资产，自动将其作为内部 `icon` 元件填充至 `elements` 中（若有子图元则一并嵌套）；当鼠标点击该按钮时，子元件亮度自动降为 80% 产生自然的点击变暗视觉反馈，松开时平滑恢复。
