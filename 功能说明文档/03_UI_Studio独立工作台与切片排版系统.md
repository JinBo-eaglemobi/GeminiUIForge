## 一、 模块核心定位

UI Studio 独立工作台是 Gemini UI Forge 针对现代游戏 UI 切片资产拼合与界面排版设立的专属工程环境。与传统 Slots 模板依赖整景设计图不同，UI Studio 采取**纯切片素材驱动架构**：支持多视图界面管理、树形素材库拖拽组装、容器专属独立视口多 Tab 编辑、自由拖拽分割线与毫秒级属性检查。

## 二、 核心功能清单

### 1. 三栏响应式架构与手势调宽系统 (Splitter System)
- **左右中三栏解耦与自由调整**：
  - 左侧复合面板、中间交互画布与右侧属性检查器通过 `VerticalSplitter` 相互解耦；
  - 基于 Compose 官方生产级 `Modifier.draggable` 一维手势封装，设置 `startDragImmediately = true` 确保指针即触即动、零启动死区；
  - 左右面板宽度支持双向自由拉伸，并具有合理的物理最小与最大边界夹具（如 240dp ~ 480dp），手势协程长效保活，彻底杜绝高亮锁死与手势中断。
- **左侧上下子面板与水平手柄 (HorizontalSplitter)**：
  - 左侧上栏为页面视图列表（ViewsPanel），下栏为树形素材库（AssetPanel）；
  - 中间镶嵌 `HorizontalSplitter` 水平分割手柄，支持上下自由调整列表与素材库的显示高度配比。

### 2. 页面视图管理系统 (ViewsPanel)
- **多页面/多场景统一管理**：
  - 支持在一个工程中创建并管理多个独立的游戏视图（如 Main 主界面、Lobby 大厅、Settings 设置弹窗、Backpack 背包等）；
  - 支持视图新建、重命名、复制副本与物理删除（含二次确认保护）；
  - 单击视图项快速在中间画布加载其图元树，双击可在顶部标签栏开启独立视口。

### 3. 多标签独立视口画布系统 (Viewport Tabs & Active Container)
- **容器专属视口新开与聚焦**：
  - 当双击画布中的复合容器（Container）时，系统自动在顶部标签栏新开以该容器命名的专属标签页；
  - 视口画面自动裁剪聚焦到该容器内部坐标系，中间画布仅渲染并接收该容器直接子模块的手势操作；
  - 彻底解决深层嵌套子图元难以选中的痛点，实现由粗到细的逐级微观排版。
- **标签页状态管理与职能单一化**：
  - 支持多标签平滑切换、独立关闭，且当前激活的标签页状态与视口缩放平移参数在工程切换时自动持久化与自愈；
  - **标签栏职能纯净化与零冗余红线**：顶部标签栏右侧专职提供“关闭全部标签页”标准图标按钮（`AppIconButton` COMPACT 阶）；新建视图入口统一且唯一收拢于左侧「视图界面」面板 Header（`ViewsPanel`），顶部标签栏绝不重复设立多余的新建视图按钮，确保视口顶端清爽、无功能混淆。

### 4. 素材切片拖拽排版与画布交互
- **切片拖拽即生成图元**：
  - 支持从左侧素材库中选中任意切片，直接拖拽至中间画布释放；
  - 系统自动根据切片真实物理分辨率初始化图元尺寸，并自动挂载对应切片资产 Hash；
- **微观对齐与智能吸附**：
  - 画布内置边缘几何对齐辅助线，图元在移动或拉伸时，靠近相邻图元或容器边缘（$\le 5\text{px}$）自动触发磁力吸附；
  - 8 方向拉伸控制锚点 100% 统一复用 `RectTransformHelper`，光标物理绝对定位。

### 5. 右侧动态属性检查器 (PropertyPanel)
- **切片排版专属极简属性**：
  - 专职于图元几何变换（X、Y、Width、Height）、不透明度（Opacity）、图元类型（Button、Image、Text、Container）；
  - **豁免生图组件**：因 UI Studio 属于纯切片排版，属性面板彻底去除冗余的 AI 生图提示词模块，保持面板紧凑纯净；
  - 数值调节一律接入 `NumberOutlinedTextField`，指针悬停即可滚轮平滑微调。

### 6. 悬浮式 AI 架构师协同入口
- 画布右下角常驻悬浮轻量级 AI 对话胶囊，一键唤起 `UIProjectAiStudioDialog` 项目级 AI 架构师；
- 架构师具备完整感知当前视口图元树、素材库清单与排版状态的能力，支持自然语言分发排版指令。

## 三、 跨模块联动关系

```
┌───────────────────────────┐      切片入库与读取  ┌─────────────────────────────┐
│                           ├────────────────────►│ 树形素材库 (UIAssetLibrary) │
│                           │      唤起校对弹窗    ├─────────────────────────────┤
│                           ├────────────────────►│ 图集导入与校对 VerifyDialog  │
│ UI Studio 独立工作台       │      状态持久化      ├─────────────────────────────┤
│ (AppScreen.UI_STUDIO)     ├────────────────────►│ 本地磁盘 asset_library.json │
│                           │      打开 AI 协同    ├─────────────────────────────┤
│                           ├────────────────────►│ UIProjectAiStudioDialog     │
│                           │      转译代码导出    ├─────────────────────────────┤
│                           ├────────────────────►│ FGUI / HTML 统一导出管线     │
└───────────────────────────┘                     └─────────────────────────────┘
```

1. **与切片导入校对弹窗联动**：外部导入 SpriteSheet 图集后，自动进入[04 切片图集导入与透明图智能去背校对系统](04_切片图集导入与透明图智能去背校对系统.md)的校对界面，完成去背与吸附后批量入库并展现在 AssetPanel；
2. **与磁盘物理文件实时双向同步**：任何素材文件的重命名、文件夹归类或删除，秒级同步更新磁盘物理文件与 JSON 元数据，详见[05 素材资产管理与磁盘物理双向同步系统](05_素材资产管理与磁盘物理双向同步系统.md)；
3. **与项目级 AI 对话中枢联动**：常驻悬浮入口一键唤起架构师，详见[06 AI多模态生成与智能体对话系统](06_AI多模态生成与智能体对话系统.md)，生成的切片排版方案可一键应用回当前视图画布；
4. **与游戏工程转译管线联动**：完成界面切片排版后，通过[07 游戏工程管线与转译导出系统](07_游戏工程管线与转译导出系统.md)一键导出为 FGUI 布局与 HTML 预览。

## 四、 行业业务规则与安全红线

1. **【素材唯一主键 Hash 守恒】**：素材切片在整个工作台内以内容 SHA-256 Hash 为唯一不可变标识，杜绝同名重命名引发的资产错乱；
2. **【分割线手势保活铁律】**：严禁在业务界面裸调手势，必须统一复用[08 全局设计系统与通用基础组件规范](08_全局设计系统与通用基础组件规范.md)中的标准 Splitter 组件，确保拖拽停止时 100% 释放拖拽状态；
3. **【视口状态无损切换】**：多标签页切换或退出进入容器视口时，原视口的缩放比例与平移偏移行程必须无损保留。
