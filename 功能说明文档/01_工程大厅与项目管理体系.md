## 二、 核心功能清单

### 1. 工程列表多模态呈现与检索
- **网格卡片模式 (Grid View)**：
  - 以响应式卡片网格自适应平铺，直观呈现项目封面缩略图；
  - 封面左上角自适应点缀类型徽章：UI Studio 独立工程悬浮高亮 `UI Studio` 标识药丸；Slots 模板工程呈现全景设计图缩略图；
  - 卡片底部明确展示项目名称、设计分辨率（如 `1920 × 1080`）、图元总数及最后修改时间戳。
- **紧凑列表模式 (List View)**：
  - 面向高密度大批量工程项目管理，提供单行紧凑数据行项，便于快速比对时间与尺寸；
  - 提供快速点击整行进入工作台能力。
- **实时关键字搜索过滤**：
  - 顶部集成 `AppSearchField` 统一搜索栏（34dp 规范高度），支持实时根据工程名称模糊匹配过滤；
  - 配备一键清除搜索关键字按钮，并实时动态刷新当前可见工程计数。

### 2. 双轨工作台自适应路由 (Dual-Track Project Routing)
- **自然属性判定**：点击工程卡片时，系统底层基于 `referenceImages.isEmpty()` 进行二元判定，绝不依赖脆弱的手动标记：
  - **进入 UI Studio 工作台**：当工程无整景设计参考图时，自动路由进入 `AppScreen.UI_STUDIO`，开启切片排版与三栏工作台（详见 [03_UI_Studio独立工作台与切片排版系统](03_UI_Studio独立工作台与切片排版系统.md)）；
  - **进入 Slots 模板工作台**：当工程包含设计参考图时，自动路由进入 `AppScreen.PROJECT_WORKSPACE`，开启图元槽位与生图工作区（详见 [02_Slots模板工作区与图元编排系统](02_Slots模板工作区与图元编排系统.md)）。

### 3. 工程新建与模板生成向导
- **新建 UI Studio 独立工程**：
  - 弹出新建对话框，允许配置项目名称、预设设计分辨率（标准 16:9 横屏如 1920×1080、1280×720，或竖屏 720×1280 等）；
  - 自动在磁盘初始化工程骨架，生成空的视图配置与专属素材库目录 `templates/{projectName}/`；
- **AI 模板分析反向新建**：
  - 支持从大厅直接唤起 `AppScreen.TEMPLATE_GENERATOR`，用户上传设计图后由大模型推理出整套图元层级树并保存为全新工程（详见 [06_AI多模态生成与智能体对话系统](06_AI多模态生成与智能体对话系统.md)）。

### 4. 资产导入导出与冲突仲裁
- **工程导出**：
  - 支持将指定工程完整打包为标准化压缩包（含配置文件、图元树结构、素材切片库、生图历史与会话报文），便于跨设备流转；
- **工程导入与冲突解决策略 (Import Conflict Resolver)**：
  - 当导入的工程在本地磁盘已存在同名目录时，系统自动拦截并弹出冲突解决弹窗（`AppImportConflictDialog`），提供三项决策：
    1. **覆盖写入 (Overwrite)**：完全以导入包数据覆盖本地旧版本；
    2. **自增重命名 (Rename)**：自动追加 `_copy` 或版本后缀新建并列工程；
    3. **跳过导入 (Skip)**：放弃导入该工程，保留本地现有工程。

### 5. 磁盘物理安全定位与破坏性防护
- **安全定位工程目录**：
  - 卡片配备文件夹快捷操作按钮；
  - 遵循三级安全定位规范：目标工程目录存在则直接打开并高亮；父目录存在则打开父目录；均不存在时优雅弹出 Toast 警告，绝不引发程序崩溃或静默无响应。
- **工程物理删除二次确认 (Destructive Action Protection)**：
  - 点击删除工程按钮时，系统绝对禁止直接执行物理抹除；
  - 强制弹出 `AppConfirmDialog` 警告卡片（严格遵循 [08_全局设计系统与通用基础组件规范](08_全局设计系统与通用基础组件规范.md) 的 440dp Alert 宽度），展示项目名称、关联素材数量以及不可恢复后果警示，确认按钮强制标注高亮警示红色（`isDestructive = true`），经用户显式确认后方才擦除磁盘目录。

## 四、 行业业务规则与安全红线

1. **【零数据丢失红线】**：导入同名工程未获用户明确裁决前，严禁任何形式的自动静默覆盖写入；
2. **【唯一主键与路径规范】**：工程名在磁盘作为目录名，严格限制非法字符（如 `\ / : * ? " < > |`），新建与重命名时前端即时校验阻断；
3. **【空工程冷启动自愈】**：首次启动或工作目录为空时，大厅提供高品质“空状态”引导卡片，引导用户一键新建或导入示例工程，杜绝白屏与茫然感。
