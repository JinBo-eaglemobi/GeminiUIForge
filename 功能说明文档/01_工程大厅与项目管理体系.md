## 二、 核心功能清单

### 1. 顶层全局导航操作链
- **工程刷新 (Refresh)**：点击循环箭头按钮，实时扫描本地磁盘 `~/.geminiuiforge/templates/` 与 Git 游戏工程目录，触发双通道冷启动自愈；
- **模板生成器向导入口 (`✨ 生成模板`)**：支持从设计图反向逆向解析出整套工程；
- **云端资产管理器 (`☁️ 云端资产`)**：提供模态弹窗，支持将本地图元资产上传至团队云端，或从云端拉取共享资源（支持 `Upload` 与 `Sync` 操作）；
- **MCP 服务中心快捷入口 (`MCP Service`)**：快速启停 18330 本地 MCP 调试服务，并支持一键配置 5 大主流 AI 客户端；
- **帮助手册 (`?`)**：内置详细的本地 Markdown 手册浏览窗口；
- **应用设置中心 (`⚙`)**：承载全系统的 6 大偏好配置中心。

### 2. 底层全局动态监控与状态栏
- **左侧业务状态回显**：展示系统全局操作最新反馈（如“就绪”、“已保存: 修改页面尺寸”等）；
- **系统硬件资源实时监控胶囊**：动态采集宿主与本进程的真实性能数据（如 `RAM: 93 MB (宿主 85%) | CPU: 0.6% (宿主 100%)`），具备超限变色预警机制；
- **MCP 通信节点状态灯**：绿色指示灯实时感知 MCP 服务是否处于活跃监听中，并显示当前无障碍语义树中已挂载的有效节点总数（如 `• MCP 通信监控 (38 节点)`）；
- **运行时控制台抽屉 (`ℹ️`)**：点击一键展开/折叠浮层日志控制台，查看底层实时分级日志输出。

### 3. 四大类工程卡片的结构与视觉规范
系统大厅以响应式网格平铺展示以下四种具备明确视觉层级的工程卡片：
1. **新建游戏引导卡片 (New Game Card)**：
   - 虚线边框设计，居中加号图标；
   - 标题：`+ 新建游戏项目`，副标题：`从 Git 仓库纳管并管理游戏项目`；
   - 点击直接唤起 [07 游戏工程管线创建向导](07_游戏工程管线与转译导出系统.md)。
2. **独立游戏工程卡片 (Game Project Card)**：
   - 左上角悬浮紫蓝渐变徽章：`🎮 游戏项目`，中央展示手柄图标；
   - 展示游戏工程名称（如 `GameMania`）、游戏包标识（如 `游戏: premierLeagueS...`）；
   - 展示底层包管理器模式（`管理模式: PNPM` 或 `NPM`）；
   - 底部展示精确到秒的最近打开时间戳，右下角配备 `打开本地目录` 与 `删除工程` 按钮。
3. **传统 Slots 模板工程卡片 (Slots Template Card)**：
   - 封面直接以全景设计效果图作为真实底图（如 Safari Spin 原图画面），左上角带加号角标；
   - 展示工程名称（如 `effect main`）、分辨率信息与最后保存时间戳；
   - 点击自适应路由直达 [02 Slots模板工作区](02_Slots模板工作区与图元编排系统.md)。
4. **UI Studio 独立工程卡片 (UI Studio Card)**：
   - 左上角悬浮紫色发光药丸：`✨ UI Studio`，中央展示层叠菱形图层图标；
   - 醒目点缀设计分辨率胶囊（如 `1920 × 1080`）；
   - 展示项目名称（如 `New UI Project`）与副标题 `本地工程`；
   - 点击自适应路由直达 [03 UI Studio独立切片排版工作台](03_UI_Studio独立工作台与切片排版系统.md)。

### 4. 通过 Gemini 生成模板子系统 (Template Generator)
点击顶栏 `✨ 生成模板` 弹出的全屏工作向导，具备**在线大模型**与**离线端侧识别**双模式：
- **☁️ 在线 AI 生成模式**：
  - 支持直接输入设计图本地绝对路径或图片网络 URL；
  - 设置目标模板工程名称；
  - 勾选 `自动切割并绑定参考图 (Auto Crop & Bind)`：大模型返回坐标后，后端自动根据边界将参考图切片并落盘绑定至各图元；
  - 提供本地文件选择器按钮快速载入大图；
  - 点击 `✨ 发送给 Gemini 分析` 调用旗舰多模态视觉模型进行图元树推理。
- **⚡ 离线极速识别模式 (零网络与免 Key 环境)**：
  - 专为无网环境或敏感设计图打造，内置两大端侧离线引擎：
    1. `传统 CV 几何轮廓分析 (Traditional CV Contour)`：基于 Canny 边缘、梯度场与微观连通域聚类；
    2. `端侧 AI 目标检测 (ONNX YOLO Engine)`：调用本地轻量级 ONNX 深度学习模型直接推理按钮、面板与文本槽位；
  - 点击 `⚡ 一键离线构建`，秒级完成模板图元树反向推导。
- **实时推理终端面板**：向导底部内嵌流式日志终端，实时高亮打印大模型握手、坐标反投影与切片裁切流水。

### 5. 应用设置 6 大偏好配置中心 (AppSettingsDialog)
点击顶栏齿轮图标唤起 520dp 标准设置弹窗，左侧 6 大偏好导航，右侧动态切换：
1. **常规设置 (General Settings)**：
   - `JVM 最大堆内存`：支持 1G / 2G / 4G / 8G 预设档位，自动写入 `~/.geminiuiforge/app.vmoptions` 并在下次启动时生效；
   - `外观主题`：支持跟随系统、深色模式（Dark）、浅色模式（Light）；
   - `布局模式`：自适应探测、宽屏沉浸、紧凑模式；
   - `界面语言`：跟随系统、简体中文、English；
   - `工程根存储目录`：自定义工程落盘的根物理路径。
2. **AI 引擎配置 (AI Engine Settings)**：
   - `Gemini API Key`：密码学掩码脱敏输入与本地加密存储；
   - `网络请求重试次数`：配置接口抖动时的容错重试次数；
   - `默认生图张数`：单次并发生成候选图片数量（默认 4 张）；
   - `默认提示词语言`：中文 / 英文；
   - `通信协议架构`：支持切换官方新一代 `Interactions API (Next-Gen)` 与旧版兼容模式；
   - `生图意图自动模型切换`：开启后智能体感知到生图指令时自动切换为专业生图模型；
   - `默认生图模型`：选用最新模型（如 `Nano Banana 2`）；
   - `AI Agent 最大工具轮询次数`：设置 Agent 单轮交互中 Tool Calling 的硬上限（出厂默认 50 轮）。
3. **提示词模板管理 (Prompt Template Manager)**：
   - 系统级收拢管理 13 种内置提示词模板（整页分析、局部重塑、规范字典、一键精炼、改图组装、SpriteSheet 坐标检测等）；
   - 支持读取本地持久化覆盖版本（`~/.geminiuiforge/prompts/`），并提供一键恢复出厂默认值对比能力。
4. **运行环境检测 (Environment Health Check)**：
   - 自动检测本地 Python 3.9+ 运行环境；
   - 实时监控深度学习与图像库状态：`Rembg (2.0.75)`、`Pillow (12.2.0)`、`ONNX Runtime (1.24.4)`；
   - 提供环境异常时的一键全自动安装、更新与卸载能力；
   - **安装全流程日志实时流式回显与留痕保活**：全流程流式捕获进程输出，安装完成或失败后日志持久化保留（绝不随状态刷新秒级闪退）；
   - **失败错误高亮与控制面板**：失败态醒目呈现红底错误原因横幅，提供“复制日志”与“收起/清除”独立控制面板；
   - **全生命周期打通统一日志系统 (AppLogger)**：进程启动命令、标准与错误输出、非零退出码及异常栈 100% 写入系统日志文件，支持开发者与运维审计回溯；
   - **多平台传统标准目录寻址与多源 10 秒链接测速择优下载**：
     - **命令输出窗口内显示官方下载地址与外链点击直达**：依赖项外层卡片保持简洁，仅在命令输出界面（`EnvironmentItemLogPanel`）的日志流中前置显示官方下载地址及各候选镜像源 URL，并将所有 `http(s)://` 链接渲染为带下划线的高亮可点击外链，点击直接调用系统默认浏览器打开；
     - **国内外多节点候选源列表与 10 秒链接测速（`DownloadSourceSpeedTester`）**：自动列出探测到的全部国内外候选下载源（涵盖国内华为云/阿里/南大/清华/腾讯/中科大镜像，以及国际/海外官方 Fastly 全球 CDN、亚太韩国 Kakao、美国 OSUOSL、欧洲瑞典 UMU、Python Legacy 等节点），执行 10 秒并发链接测速并输出各源响应耗时，自动择优使用访问最快的下载源；
     - **实时下载速度与进度原位刷新**：下载过程中按滑动时间窗口实时计算并原位刷新当前下载进度与实时网速（`MB/s` / `KB/s`）；
     - **命令输出窗口按需点击折叠/展开与卸载后自动清理**：当且仅当某个依赖项存在命令输出窗口（`EnvironmentItemLogPanel`）时，其上方的依赖项行才激活点击折叠/展开功能（带折叠箭头与折叠态状态标识）；未执行任何命令输出的项无折叠功能与图标；在执行卸载时独立展示“正在卸载...”状态，且卸载成功后自动清空并移除命令输出窗口、同步取消折叠功能；
     - **软件安装/卸载时自动检测并前置安装 WinGet**：在 Windows 下执行软件安装或卸载（如 Python）时，若检测到系统尚未安装 `winget`，直接在当前命令输出流中自动前置安装 `winget`（输出官方地址、执行 10 秒多源链接测速、显示实时下载速度、支持 `Add-AppxPackage` 与内置 Administrator 账户下独立解压部署兜底），安装完成后无缝继续执行目标软件的安装或卸载，并支持 `winget` 动态版本 ID 卸载与 Windows 注册表 `QuietUninstallString` 双通道静默卸载；
     - **动态寻址器（`PythonEnvResolver`）**：严格扫描 Windows / macOS / Linux 传统操作系统官方标准安装目录（如 Windows `%LOCALAPPDATA%\Programs\Python\Python3*`、`%ProgramFiles%\Python3*`，macOS `/opt/homebrew/bin/python3`、`/Library/Frameworks/Python.framework/Versions/*` 等）以及 `winget` 多路径（`PATH`、`WindowsApps` 别名、`%LOCALAPPDATA%\Programs\WinGet`、`Get-AppxPackage` 安装目录），突破 JVM 缓存旧 `PATH` 限制实现安装后免重启即时识别。
5. **快捷键一览与自定义 (Keybindings)**：
   - 集中呈现全系统全局快捷键映射（撤销 Ctrl+Z、重做 Ctrl+Y、保存 Ctrl+S、复制 Ctrl+C、粘贴 Ctrl+V、剪切 Ctrl+X、重命名 F2、删除 Delete、自适应视口等）。
6. **关于软件 (About)**：
   - 显示当前桌面客户端版本号（如 v1.0.7）、在线检查更新入口、版权信息与开源协议。

## 四、 行业业务规则与安全红线

1. **【零数据丢失红线】**：导入同名工程未获用户明确二次裁决前，严禁任何形式的自动静默覆盖写入；
2. **【唯一主键与路径规范】**：工程名在磁盘作为目录名，严格限制非法字符（如 `\ / : * ? " < > |`），新建与重命名时前端即时校验阻断；
3. **【空工程冷启动自愈】**：首次启动或工作目录为空时，大厅提供高品质“空状态”引导卡片，引导用户一键新建或导入示例工程，杜绝白屏与茫然感；
4. **【真实鼠标自动化接管安全红线】**：凡在大厅中执行真实鼠标手势测试或点击模拟时，必须强制弹出置顶弹窗并执行 3 秒倒计时，操作结束后立即告知并在 3 秒后自动关闭。
