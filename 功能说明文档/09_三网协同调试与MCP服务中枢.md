## 一、 模块核心定位

## 二、 核心功能清单

### 1. 第一梯队：IntelliJ IDEA 研发宿主网 (idea_*)
- **精准毫秒级局部增量编译 (`idea_build_project`)**：
  - 代码变动后，必须且仅传入修改的具体文件清单（`filesToRebuild = [...]`）；
  - 毫秒级返回结构化编译结果（`isSuccess`、`problems` 列表），确认 0 错误后再向下推进；
  - **【全量 Gradle 绝对禁令】**：日常迭代中严禁发起全量 Gradle 任务（如 `:desktopApp:compileKotlin`），彻底杜绝冗长等待与进程死锁；
- **运行时实机断点取证 (`xdebug_*`)**：
  - 核心宗旨在于直接审查内存真实数据，杜绝凭空猜测；
  - 优先打设非挂起日志断点（`logExpression`），不中断 UI 渲染；
  - 数据核验完毕后，强制彻底清除所有断点（`xdebug_remove_breakpoint(owner = "agent")`），恢复现场。

### 2. 第二梯队：Compose 官方专属热重载体系 (compose-hot-reload_*)
- **桌面窗口常驻保活铁律**：
  - 热重载体系的核心价值在于桌面窗口常驻保活、内存与导航状态不丢；
  - **绝对禁止因局部代码修改或工具超时擅自调用 `Stop-Process` 或 `kill` 强杀桌面进程**；
- **官方三级生效标准**：
  1. **第一级（状态级零杀重置，`reset_ui`）**：丢弃 `remember` 运行时状态并从根重构 UI，耗时 < 50ms；
  2. **第二级（字节码热替换，`reload`）**：日常 UI 与逻辑修改后发起热更，闭环轮询 `status()` 直至状态稳定；
  3. **第三级（官方原生极速重启，`restart`）**：核心数据契约或依赖变更导致无法热更时，由 Hot Reload 守护进程以既有参数极速拉起新进程并自动重连（耗时仅 3~5 秒）；
- **MCP 掉线原生自愈与 3 次物理熔断**：
  - 热更通道掉线时，优先执行非侵入式自动重连，允许连续重试最多 3 次；连续 3 次失败触发物理熔断，强制弹出决策卡片交由用户裁决，绝不私自杀进程。

### 3. 第三梯队：GeminiUIForge 业务级 MCP (端口 18330)
- **Compose 动态语义感知与拟人化交互**：
  - 调用 `get_semantic_tree` 实时获取运行中 UI 的原生无障碍语义树；
  - 杜绝硬编码易失性数字 Node ID，动态检索文本与特征后调用 `click_ui_node` / `set_ui_input_text` 进行真实事件分发；
- **实机物理窗口审查与二元截图铁律 (Dual-Mode Visual Inspection)**：
  - **微观组件对齐特写**：单图元、按键或切片校准时，截取目标局部区域并外扩 32~48px 呼吸边距，呈现 1:1 细节；
  - **宏观工作台全景审查**：涉及三栏布局、标签页联动、画布视口全景时，必须截取整窗大图；
  - **双层回显铁律**：数据层输出磁盘保存绝对路径（`C:\Users\...\window_*.webp`）；展示层必须将其转换为本地方案链接（`http://localhost:1234/C/...`）并使用 Markdown 图片语法直接渲染本体画面，严禁口头断言。

- **全业务模块热更与验证闭环**：
  无论是 [01 工程大厅](01_工程大厅与项目管理体系.md)、[02 Slots模板工作区](02_Slots模板工作区与图元编排系统.md)、[03 UI Studio独立工作台](03_UI_Studio独立工作台与切片排版系统.md)、[04 切片图集校对](04_切片图集导入与透明图智能去背校对系统.md)、[05 素材资产管理](05_素材资产管理与磁盘物理双向同步系统.md)、[06 AI多模态生成](06_AI多模态生成与智能体对话系统.md)、[07 游戏工程管线](07_游戏工程管线与转译导出系统.md) 还是 [08 全局设计系统](08_全局设计系统与通用基础组件规范.md)，任何代码修改均必须通过 IDEA MCP 的 `idea_build_project` 进行单/多文件增量编译初筛，随后通过 Compose 官方热重载秒级生效，杜绝全量 Gradle 冗长构建；

  业务 MCP (18330) 暴露的所有工具（包括模板提取、用户通知、节点交互等）均统一挂载在 [06 分册中定义的 ToolHub 单例中枢](06_AI多模态生成与智能体对话系统.md) 中，遵循中立的 `ToolDefinition` 协议；

  截取的窗口图片直接内嵌渲染于 AI 对话与工程日志中，为 [04 分册中的去背与吸附校对](04_切片图集导入与透明图智能去背校对系统.md) 以及 [02 分册中的图元对齐](02_Slots模板工作区与图元编排系统.md) 提供了 100% 真实透明的物理事实依据。

## 四、 行业业务规则与安全红线

1. **【严禁滥杀冷启铁律】**：严禁将冷重启应用作为偷懒手段，守护进程与桌面端必须最大化保活常驻；
2. **【超时防重杀红线】**：运行配置命令超时到期绝不等于进程消亡，严禁盲目发起第二次同名运行，防止 IDEA 发送 `SIGTERM` 强杀旧进程导致死锁；
3. **【审查黑盒杜绝红线】**：调用截图功能后必须即时向用户渲染呈现截屏画面本体，确保视觉审查过程完全透明、公开可核验。
