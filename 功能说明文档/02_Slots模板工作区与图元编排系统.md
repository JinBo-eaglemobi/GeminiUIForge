## 一、 模块核心定位

Slots 模板编排工作台是专为具备全景设计参考图的游戏项目打造的视觉工程中枢。它在画布舞台中将视觉图元（UIBlock）与设计参考图精准对应，支持绝对与相对空间无损转换、几何外切微调、图层树层级联动以及中英双语 AI 资产生成与替换。

## 二、 核心功能清单

### 1. 画布交互舞台与手势控制 (CanvasArea)
- **自由平移与视口缩放**：
  - 支持快捷键 `Ctrl + 滚轮` 平滑缩放视口（缩放比 10% ~ 500%），支持按住空格或中键拖动画布自由平移；
  - 配备「适应画布 (Fit to Viewport)」一键重置功能，自动以当前视口尺寸居中等比适配整景底图；
- **画布命中选择的层级门禁规范 (Hierarchy Hit-Test Gate)**：
  - **二元命中域机制**：
    1. **全局主视图模式**：画布仅允许命中顶层根图元，严禁任何深层穿透点选，杜绝误触内部深层组件；
    2. **组编辑模式 (Group Edit)**：双击顶层容器进入该容器专属编辑链，此时画布严格仅允许点选该容器的直接子组件；
  - **单一命中管道**：单击选中、双击进出组与框选手势 100% 统一复用同一个碰撞算法管道，彻底消除手势冲突。

### 2. 控制手柄与统一几何变换 (RectTransformHelper)
- **8 方向拉伸控制手柄**：
  - 选中图元四周呈现 8 个控制锚点（四角与四边中心）；
  - **光标逻辑位置直接锚定铁律**：控制点拖拽坐标直接锚定在当前光标反投影到画布的逻辑绝对坐标（`screenToLogical(cursor)`），光标移动到哪个逻辑像素，控制点绝对赋值到该像素，**彻底消除每帧增量累加（`dragAmount / scale`）导致的丢帧与滞后缺陷**；
  - 支持等比缩放、中心对称缩放与正圆锁定（1:1 保持）。

### 3. 多层树状图元层级坐标系架构
- **空间二元解耦与代数守恒**：
  - **局部空间 (Local Space)**：图元数据模型持久化存储的永远是相对于其直接父容器的局部相对坐标（`bounds`），防止层级拓扑破坏；
  - **全局空间 (Global Space)**：全景视口渲染、画布命中、选区框选与全图切片裁剪，统一运行在全局绝对坐标系（`absoluteBounds`）下；
  - **无参推导管道**：通过扁平位移累加实现零临时垃圾对象分配的高性能转换，且严格遵守代数守恒：`block.toLocalBounds(block.absoluteBounds) == block.bounds`。

### 4. 业务核心图元规则与约束
- **全屏游戏背景底图规范 (BACKGROUND)**：
  - 顶层背景图元尺寸必须恒等于全屏画布尺寸；
  - 系统内置初次加载自动自愈机制，无条件将背景模块的 `bounds` 与 `cropRect` 重置为 `[0, 0, canvasWidth, canvasHeight]`，彻底根绝画布边缘留白；
- **纯容器与组合占位层规范 (CONTAINER & isPureContainer)**：
  - 纯容器仅作为排版分组虚节点，自身完全通透可见，**绝对不参与任何 AI 图片资源生成**；
  - 批量生图自动排除所有纯容器；属性面板自适应隐藏图片资产卡片，仅保留几何坐标与容器内部重塑功能；
- **底座外壳完整性与正圆外切铁律**：
  - 复合图元外包矩形必须完整包覆其承载的物理底座、外壳框架与边缘厚度，严禁腰斩底座；
  - 正圆轮廓组件宽高比严格恒等于 1:1，四边精准外切。

### 5. 参考图区域解耦与切片裁剪 (Decoupled Reference Area)
- **参考区域与显示坐标二元解耦**：
  - 模块在画布上的显示大小与坐标（`bounds`）和 AI 生图的局部参考区域（`cropRect` 与切片 `referenceImage`）**完全独立**；
  - 调整参考区域时，系统仅更新 `cropRect`，绝不篡改模块自身的排版 `bounds`。

### 6. 图层层级树与祖先隐藏视觉联动 (HierarchySidebar)
- **树形拓扑管理**：支持图元拖拽调序、层级重排、重命名、图层锁定与快速定位；
- **祖先隐藏同步变暗联动**：
  - 任一祖先模块被隐藏时，其整棵子树的行项（图标、名称、ID）同步继承变暗状态（透明度 0.4/0.3）；
  - 每个节点的眼睛开关永远仅控制自身的 `isVisible` 状态，不篡改显示数据。

### 7. 右侧统一属性面板与双语 AI 生图编辑器
- **精确数值输入**：集成 `NumberOutlinedTextField`，支持指针悬停滚轮微调与自适应步长；
- **标准双语生图组件 (BilingualPromptEditor)**：
  - 单行分段按钮实现中英文双语无缝切换与跨语言占位提示；
  - 胶囊式 AI 提示词优化入口，自带加载动画与防重点击；
  - 变动感知与显式确认同步：仅在用户显式点击确认后同步回数据模型并持久化。

## 三、 跨模块联动关系

```
┌───────────────────────────┐      图元树同步      ┌─────────────────────────────┐
│                           ├────────────────────►│ 左侧图层层级树 (Hierarchy)    │
│                           │      双向属性驱动    ├─────────────────────────────┤
│                           ├────────────────────►│ 右侧统一属性检查面板         │
│ Slots 模板工作区           │      批量任务下发    ├─────────────────────────────┤
│ (PROJECT_WORKSPACE)       ├────────────────────►│ [批量生图弹窗 BatchAssetGen](06_AI多模态生成与智能体对话系统.md)   │
│                           │      局部参考裁剪    ├─────────────────────────────┤
│                           ├────────────────────►│ 选区裁剪 UniversalRegion      │
│                           │      编译产物导出    ├─────────────────────────────┤
│                           ├────────────────────►│ [编译器 CompilerService](07_游戏工程管线与转译导出系统.md)       │
└───────────────────────────┘                     └─────────────────────────────┘
```

1. **与批量生图中心联动**：一键拉取当前所有非容器且配置了提示词的图元，按序分发至后台生图服务（详见 [06_AI多模态生成与智能体对话系统](06_AI多模态生成与智能体对话系统.md)）；
2. **与本地磁盘缓存联动**：生成的图片自动落盘在 `templates/{projectName}/assets/{blockId}/`，支持回溯报文重新自愈；
3. **与编译导出服务联动**：将当前排版树与资产配置编译生成标准工程产物（详见 [07_游戏工程管线与转译导出系统](07_游戏工程管线与转译导出系统.md)）。

## 四、 行业业务规则与安全红线

1. **【严禁全量 Gradle 编译】**：工作台代码修改与调试一律通过局部增量构建与热重载进行，严禁全量构建等待（详见 [09_三网协同调试与MCP服务中枢](09_三网协同调试与MCP服务中枢.md)）；
2. **【防误触丢失红线】**：画布图元移动与缩放均支持完整的撤销/重做堆栈；退出未保存工程时强制弹出防丢失挽留弹窗（遵循 [08_全局设计系统与通用基础组件规范](08_全局设计系统与通用基础组件规范.md)）。
