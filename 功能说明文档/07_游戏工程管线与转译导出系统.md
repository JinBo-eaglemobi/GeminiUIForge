## 一、 模块核心定位

游戏工程管线与转译导出系统是 Gemini UI Forge 面向生产环境的交付终端。它将设计排版好的图元拓扑、切片素材与样式配置，编译转换为游戏引擎（如 LayaAir、FairyGUI、Cocos 等）与 Web 端可以直接消费的工程骨架、UI 布局配置 JSON、伴生精灵图集，并提供实时的蒙版比对与集成测试环境。

```
┌────────────────────────────────────────────────────────────────────────┐
│                        游戏工程管线与转译导出体系                        │
├────────────────────────────────────────────────────────────────────────┤
│ 1. 游戏工程创建向导 (GAME_PROJECT_MANAGER)                              │
│    └─ 初始化向导: 工程表单配置 ─► 游戏模式选型 ─► 本地依赖与环境就绪检测 │
├────────────────────────────────────────────────────────────────────────┤
│ 2. 游戏项目专属工作台 (GAME_PROJECT_WORKSPACE)                          │
│    ├─ 工程代码资源树管理 (GameConfig.json / UILayout.json 结构呈现)   │
│    ├─ 内置 HTML 实时热重载视口 (即时预览排版与交互逻辑)                 │
│    └─ 统一编译器服务 (CompilerService: rootDir / outputDir / 资产混淆)  │
├────────────────────────────────────────────────────────────────────────┤
│ 3. 产物校验与蒙版比对 (OverlayPreviewDialog)                           │
│    └─ 实时图层蒙版重叠比对: 原设计图半透明覆层 ◄─► 生成排版 1:1 几何校对│
└────────────────────────────────────────────────────────────────────────┘
```

## 二、 核心功能清单

### 1. 游戏工程创建向导 (GameProjectCreateScreen)
- **多模板选型支持**：
  - 支持 Slots 旋转游戏模板、通用休闲游戏模板、含/不含 Spine 骨骼动画模板；
- **环境就绪与依赖检测**：
  - 自动检测本地开发环境（Node.js、npm 依赖、专用游戏框架类库路径）；
  - 缺失依赖时给予一键拉取或自动链接建议，杜绝因环境残缺导致后续运行报错。

### 2. 游戏项目专属工作台 (GameProjectWorkspaceScreen)
- **工程骨架结构化呈现**：
  - 清晰呈现游戏项目的主页面、组件列表、UI 布局 JSON、声音素材与核心脚本；
- **HTML 页面实时预览与测试**：
  - 借助 JetBrains IDE 内置 Web 服务（端口 63342）或内置浏览器组件直接导航呈现 HTML 测试界面；
  - 严禁私自拉起独立的外部 HTTP 服务，100% 遵循宿主原生能力规范。

### 3. 编译导出配置中枢 (CompileConfigDialog & CompilerService)
- **三级可配置导出参数**：
  - **运行环境根目录 (`rootDir`)**：指定游戏主工程的物理根路径；
  - **资源保存目录 (`outputDir`)**：指定编译后 UI 配置文件与伴生切片的输出目录；
  - **资源混淆与安全保护 (`obfuscateAssets`)**：支持生产级资产 Hash 混淆与路径打散，防止敏感商业素材被外部轻易爬取；
- **持久化配置中心兜底**：
  - 编译配置持久化保存在用户工作区配置中，下次打开自动回填，无需重复配置。

### 4. 实时图层蒙版比对预览 (OverlayPreviewDialog)
- **1:1 几何绝对校对**：
  - 在导出前或排版后，随时一键唤起全景蒙版预览弹窗；
  - 将原始设计参考图以半透明方式覆盖在当前编译排版图层之上；
  - 支持滑动条无级调节蒙版不透明度（0% ~ 100%），快速暴露出文字偏移、按键错位、底座截断等微观缺陷。

## 四、 行业业务规则与安全红线

1. **【严禁私起独立 HTTP 服务】**：HTML 测试与预览必须复用 IDE 原生或内置轻量环境，禁止在后台自起未管理的 HTTP 服务进程；
2. **【单一终端编译校验红线】**：凡涉及命令行编译验证，一律且仅指定单一终端模块编译任务（如 `:desktopApp:compileKotlin`），严禁并列上游 `:shared` 任务；
3. **【空路径阻断拦截】**：未指定 `rootDir` 或 `outputDir` 时，系统在弹窗层严格阻断并弹出 Toast 警示，杜绝将文件写到非法未定义路径。
