## 一、 系统定位与核心价值

**Gemini UI Forge** 是一套面向现代跨平台游戏界面的**AI 驱动型工业级 UI 辅助设计、切片排版与代码转译工作台**。系统深度融合多模态大语言模型（Google Gemini 等旗舰模型）、本地无损图像去背推理引擎（RembG / ONNX）、CV 计算机视觉几何轮廓解析、Compose Multiplatform 声明式渲染与工业级编译转译管线。

```
┌────────────────────────────────────────────────────────────────────────┐
│                        Gemini UI Forge 核心工作流                        │
├─────────────────┬──────────────────┬─────────────────┬─────────────────┤
│  1. 资产与模板输入 │  2. 智能解析与去背 │  3. 画布编排与对齐 │  4. 产物编译与转译│
│  - 设计全景参考图   │  - 本地深度抠图    │  - 独立视口多 Tab   │  - FGUI / HTML  │
│  - 外部图集 / 切片 │  - 连通岛边缘吸附  │  - 8 向绝对锚定手柄 │  - 游戏工程骨架 │
│  - 纯净项目新建   │  - 双向微观自适应  │  - 属性检查与双语AI │  - 多端资产分发 │
└─────────────────┴──────────────────┴─────────────────┴─────────────────┘
```

## 二、 界面拓扑与工作台体系

系统采用单活动多屏幕（Single Activity, Multi-Screen Architecture）响应式设计，以统一路由中心驱动六大核心工作台：

```
                           ┌─────────────────────────┐
                           │      全局应用顶部导航栏    │
                           │       (AppTopBar)       │
                           └────────────┬────────────┘
                                        │ 路由分发
        ┌───────────────────────────────┼───────────────────────────────┐
        ▼                               ▼                               ▼
┌─────────────────┐           ┌─────────────────┐           ┌─────────────────┐
│  工程大厅主工作台 │           │   Slots 模板工程  │           │   UI Studio     │
│   (HOME 屏幕)    │           │ (PROJECT_WORKSPACE)│          │ 独立切片排版工作室│
└───────┬─────────┘           └─────────┬───────┘           └─────────┬───────┘
        │                               │                               │
        ├───────────────────────────────┼───────────────────────────────┤
        ▼                               ▼                               ▼
┌─────────────────┐           ┌─────────────────┐           ┌─────────────────┐
│ AI 模板生成器    │           │  游戏工程创建向导 │           │  游戏项目专属工作台│
│(TEMPLATE_GENERATOR)│        │(GAME_PROJECT_MANAGER)│      │(GAME_PROJECT_WORKSPACE)│
└─────────────────┴───────────┴─────────────────┴───────────┴─────────────────┘
```

## 三、 双轨工程路由机制 (Dual-Track Architecture)

系统在数据底层采用**零侵入、自然属性解耦**的双轨判定架构，绝不在数据结构中新增冗余枚举：

```
                    用户在工程大厅点击项目卡片
                                │
                  是否存在整景设计参考图？
                 (referenceImages.isEmpty()?)
                                │
               ┌────────────────┴────────────────┐
               │ 是 (True)                       │ 否 (False)
               ▼                                 ▼
      【独立 UI Studio 工程】            【传统 Slots 模板工程】
      - 封面标记「UI Studio」药丸         - 封面呈现设计参考原图
      - 路由至 [UI Studio](03_UI_Studio独立工作台与切片排版系统.md)       - 路由至 [Slots 工作台](02_Slots模板工作区与图元编排系统.md)
      - 素材驱动，无生图提示词要求          - 图元对应设计图槽位，支持AI生成替换
```

   ┌─────────────────────────────────────────────────────────────┐

   │  - AppGlobalState (全局主题/语言/快捷键/编译配置/系统监控)       │
   │  - ProjectState ([Slots 模板树](02_Slots模板工作区与图元编排系统.md)、生图资产映射) │
   │  - UIStudioState (视图树、[UIAssetLibrary 素材库](05_素材资产管理与磁盘物理双向同步系统.md))   │

                  │                               │

                  │                               │
   ┌──────────────┴──────────────┐ ┌──────────────┴──────────────┐
   │     2. 智能算法与推理中枢     │ │     3. 交互规范与外设驱动中枢   │

## 五、 全局质量与工业级规范准则

本系统所有模块开发与功能演进，严格遵循以下核心准则：

1. **绝对事实与可验证性**：所有图元尺寸、参考区域、吸附边界均以真实像素为基准，杜绝主观臆测与相对增量累加误差；
2. **破坏性操作二次确认**：凡涉及磁盘物理删除、模板清空、工程重置操作，强制弹出 `AppConfirmDialog` 并使用高危警示样式；
3. **零代码纯净说明**：各分册功能说明文档专注于功能逻辑、交互形态、联动边界与使用规范，不掺杂易变代码片段，保持文档长效可用；
4. **功能文档生命周期闭环**：代码功能变更前必须先核对功能文档；功能交付后必须主动同步更新文档，杜绝文档与实现脱节。
