## 一、 模块核心定位

在游戏 UI 工业化开发中，美术往往交付整张包含数十个按钮、图标与文本底座的复合切片图集（SpriteSheet）。**切片图集导入与透明图智能去背校对系统**专职于将外部图集快速导入、高精度抠除背景、基于计算机视觉与 Alpha 连通岛自动将粗糙选区紧致外切贴合至各独立图元实体，并以清晰直观的微观校对画布确保 100% 准确入库。

## 二、 核心功能清单

### 1. 外部图集资产解析与导入管线
- **多数据源兼容**：
  - 支持拖拽单张高清 PNG/JPG 图像；
  - 支持导入配带有 JSON/YAML 坐标映射表的工业级 SpriteSheet 切片包；
  - 若无坐标表，支持内置轮廓初筛算法自动提取候选图元线框。

### 2. 本地 Python 深度去背系统 (LocalMattingService / RemBG)
- **环境自检与静默驱动**：
  - 自动探测本地 Python 运行时与虚拟环境，环境缺失时引导自动就绪；
  - 针对大图进行无损 Alpha 通道分割，毫秒级输出高质量透明底图。
- **600dp 宽窗体 Task 步骤列式清单 (MattingTaskProgressCard)**：
  - 遵循用户严苛的人机工程学体验要求，窗体给足 600dp 物理宽度，单行通栏结构；
  - 将去背拆分为 4 个真实核心任务步骤，严禁使用虚假定时器，由底层日志流式真实驱动：
    1. **读取源图像数据**：检查文件完整性并载入内存显存；
    2. **加载深度神经网络模型**：初始化 RemBG/ONNX 权重文件；
    3. **执行图元实体透明抠图推理**：执行 Alpha 通道精细分割与边缘抗锯齿；
    4. **保存透明底图与资产回写**：物理持久化至本地磁盘临时与资产缓存；
  - **步骤三态与独立净耗时药丸 (MattingTaskStepRow)**：
    - 状态图标：待执行（灰色等待）、执行中（动态旋转菊花）、已完成（绿色对勾）、异常失败（红色感叹号）；
    - 步骤行尾配备高对比度深色耗时药丸，精确呈现每步净耗时（如 `0.23s`、`1.45s`）。

### 3. 透明底图各向独立连通岛智能吸附引擎 (SmartEdgeSnapper)
针对去背后整图转为 Alpha 透明图的复杂场景，系统彻底根治了旧算法的严重缺陷，确立了行业领先的吸附算法：

```
                    用户点击「一键智能吸附 (Alt+A)」
                                   │
              提取粗选框局部视口二值前景掩码 (Alpha > 28)
                                   │
              3x3 结构元微观膨胀 1 次 (连接镂空与细碎断笔)
                                   │
              枚举局部所有连通实体岛 (Connected Islands)
                                   │
              计算 IoU 重叠度与中心点欧氏距离联合打分
                 Score = IoU / (1.0 + Dist * 0.05)
                                   │
              锁定全局最优专属连通岛 (100% 免疫相邻图元串通)
                                   │
         ┌─────────────────────────┴─────────────────────────┐
         │                                                   │
   粗框画大 (留白多余)                                 粗框画小 (截断边缘)
         │                                                   │
向内紧致收缩 (Tight Trim)                           向外微调外切 (Snap Outward)
         │                                                   │
         └─────────────────────────┬─────────────────────────┘
                                   │
               四周外扩 2px 优雅呼吸边距并施加尺寸硬夹具
                                   │
                         输出精准微观紧致矩形
```

- **三大核心算法突破**：
  1. **彻底废除全局泛洪漫延 (No Flood Fill)**：杜绝沿透明羽化噪点流窜到紧挨着的隔壁图元；
  2. **最佳重叠度 (IoU) 与中心距离联合打分**：即使组件紧密相邻（例如奖金展台 `WIN_Banner` 与正下方的按键 `Gift_Button` 物理贴合），每个图元也只会精准锁定与自己几何中心匹配的连通岛，**相互之间 100% 独立，零吞噬、零膨胀**；
  3. **双向自适应修剪 (Bidirectional Trim & Snap)**：
     - **向内修剪**：大模型预测的粗框若偏大，自动向内收缩剔除多余空白；
     - **向外微调**：线框若切断了发光边缘，自动外切至实体物理边缘；
     - 四边补充 2px 呼吸边距，彻底对齐图二严苛标准。

### 4. 微观校对画布与手势操作 (AssetSliceCanvas)
- **物理像素级微调**：
  - 画布底衬经典 Alpha 灰白棋盘格，极度清晰地暴露每个图元的边缘抗锯齿与留白情况；
  - 选区支持鼠标直接拖拽控制手柄微调，右侧属性面板支持键盘上下方向键逐像素步进调整；
- **全链路历史快照与撤销重做 (Snapshot & Undo/Redo)**：
  - 弹窗内置独立的撤销（`Alt + Z`）与重做（`Alt + Y`）堆栈，吸附不满意可一键撤销。

## 三、 跨模块联动关系

```
┌─────────────────────────────────┐      唤起弹窗      ┌─────────────────────────────┐
│ UI Studio 素材库 (AssetPanel)   ├──────────────────►│ 切片图集导入与校对弹窗       │
└─────────────────────────────────┘                   │ (AssetSliceVerifyDialog)    │
                                                      └──────────────┬──────────────┘
                                                                     │
                                      ┌──────────────────────────────┼──────────────────────────────┐
                                      ▼                              ▼                              ▼
                       ┌─────────────────────────────┐┌─────────────────────────────┐┌─────────────────────────────┐
                       │ 本地 Python 去背推理服务     ││ 智能边缘吸附引擎            ││ 树形素材库持久化             │
                       │ (LocalMattingService)       ││ (SmartEdgeSnapper)          ││ (templates/.../assets)      │
                       └─────────────────────────────┘└─────────────────────────────┘└─────────────────────────────┘
```

1. **与 UI Studio 素材面板联动**：校对完成点击「全部入库」后，系统自动将所有紧致切片物理切出，生成 Hash 主键并收录到当前工程素材库，详见[03 UI Studio独立工作台与切片排版系统](03_UI_Studio独立工作台与切片排版系统.md)与[05 素材资产管理与磁盘物理双向同步系统](05_素材资产管理与磁盘物理双向同步系统.md)；
2. **与全局基础设计组件联动**：弹窗宽度与进度卡片严密遵循[08 全局设计系统与通用基础组件规范](08_全局设计系统与通用基础组件规范.md)规范，杜绝魔法数字与样式割裂；
3. **与撤销历史中心联动**：每次一键吸附或手动拖拽修改前均自动创建历史内存快照，保证试错成本为零。

## 四、 行业业务规则与安全红线

1. **【吸附防膨胀熔断红线】**：吸附算法中宽高相对初始选区膨胀严禁超过 15%，一旦超限强制判定为异常并自动放弃修改；
2. **【去背日志真实流式铁律】**：去背进度卡片严禁手写固定延时 mock，必须从真实 Python 进程的标准输出与事件回调中捕获步骤推进与耗时；
3. **【切片物理坐标整数化】**：切片截取必须取整数像素坐标（Round/Floor），严禁亚像素截断引发模糊。
