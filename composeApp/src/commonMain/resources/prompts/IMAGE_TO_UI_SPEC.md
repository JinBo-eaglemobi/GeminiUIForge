# 通用游戏 UI 模块识别解析与资产生成规范 (IMAGE_TO_UI_SPEC)

本规范定义了从游戏设计稿/全景截图逆向识别、解析并生成结构化 UI 模块系统（UIBlock）的工业级标准。可作为开发者设计指南，亦可作为系统级 Prompt 供多模态视觉大模型（如 Gemini）复用。

---

## 一、 多层级模块树架构 (Hierarchical UI Topology)

1. **画布绝对基准 (Canvas Bounds)**：
   - 全景页面的 `width` 与 `height` 严格代表输入设计图的原始逻辑画布分辨率（如 1080×1920 或 1280×720）；
   - 所有顶层根模块（Root Blocks）的坐标必须位于 `[0, width]` 与 `[0, height]` 绝对范围内。

2. **嵌套局部相对性 (Local Relative Coordinates)**：
   - 当图元在视觉上归属于某个父级容器（如弹窗面板、轮盘底座、头部导航、底部控制栏）时，**必须建立父子嵌套关系**，放入父模块的 `children` 列表中；
   - **子模块的 `bounds` 永远是相对于直接父容器左上角的局部相对坐标**，禁止直接存储全局绝对坐标，确保层级相对拓扑守恒。

## 二、 核心组件分类字典 (UIBlockType)

| 类型标识 | 视觉定义与职责说明 | 是否容器 |
| :--- | :--- | :---: |
| **`BUTTON`** | 通用交互按钮（确认、充值、关闭、菜单等），通常带有立体质感与光效 | 否 |
| **`SPIN_BUTTON`** | 游戏核心旋转/抽奖大按钮，通常为豪华圆形或显眼胶囊外观 | 否 |
| **`IMAGE`** | 独立静态图像、标志 Logo 或装饰性图形 | 否 |
| **`SYMBOL`** | **转轴符号项/游戏专属图标**（宝石、金币、主题符号）。不承担网格排列，仅定义自身尺寸与中英文提示词 | 否 |
| **`TEXT`** | 纯文本展示区、数值标签或艺术字区域 | 否 |
| **`INPUT`** | 文本输入/编辑框，带有光标指示与输入底板 | 否 |
| **`VIEW`** | 通用内容面板、半透明底托卡片、边框容器或弹窗框架 | 是 |
| **`REEL`** | **转轴核心容器**。定义网格行列（`rows`, `columns`）与滚动排版逻辑 | 是 |
| **`HEADER`** | 顶部通栏导航栏（包含大标题、金币展示、菜单按钮等） | 是 |
| **`FOOTER`** | 底部状态栏或快捷操作底座（通常容纳压注、中奖、旋转按钮等） | 是 |
| **`WIN_DISPLAY`** | 赢分数字展示框，带有装饰边框与数值显示区 | 是 |
| **`BACKGROUND`** | 全屏游戏沉浸式主题背景底图 | 否 |

## 三、 转轴网格 (REEL) 与符号集 (SYMBOL) 解耦标准

1. **职责彻底分离原则**：
   - **转轴容器 (`REEL`)**：负责定义网格的物理尺寸、以及行数（`rows`）与列数（`columns`），其在画布上的位置即网格整体区域；
   - **转轴符号 (`SYMBOL`)**：作为转轴的图元模板项（Item Template），**不需要相对排列坐标**！
2. **符号尺寸计算与定义**：
   - 符号的 `bounds` 仅用于承载自身的物理长宽，即 `SerialRect(0f, 0f, width, height)`；
   - **默认基础宽高**由转轴网格自适应推导：
     $$\text{DefaultWidth} = \frac{\text{ReelWidth}}{\text{Columns}}, \quad \text{DefaultHeight} = \frac{\text{ReelHeight}}{\text{Rows}}$$
   - 符号亦可具备专属的自定义尺寸；符号在网格内的排列呈现纯粹由转轴自身的网格算法驱动。

## 四、 资产生成双语提示词标准 (Prompt Specification)

每一个 `UIBlock` 均需配备独立完备的生成文案：
1. **`userPromptEn`（英文扩散提示词）**：
   - 面向 AI 图像生成模型的高保真描述；
   - 必须详尽刻画材质（如 polished gold, frosted glass）、光影（neon bloom, rim lighting, 3D highlights）、表面纹理与美术风格；
   - 对单体组件要求置于平整纯色高对比度背景上，以便无损提取 Alpha 透明通道；
2. **`userPromptZh`（中文意图与业务描述）**：
   - 清晰阐述组件在游戏或页面中的设计意图、功能交互与视觉特征。
